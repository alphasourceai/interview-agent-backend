Launch checklist

three areas
one checklist

Work through these before sharing candidate links with applicants.

roles & links
  • Each open role is created and set to the correct status
  • Candidate links are copied from the role and tested
  • Links for closed or filled roles are retired, not reused
entities & access
  • Entities match your organization’s structure
  • Members are assigned to the correct entity
  • CSV import was used for any bulk entity or member setup
automation & support
  • Automation criteria and the scheduling link are reviewed
  • The Review Candidates approval workflow is understood
  • The team knows how and when to contact Support
before you launch

Confirm every item above before sharing candidate links with applicants. You can revisit this list any time your setup changes.

Entities & member access

right scope
right access

Roles, Candidates, and Members can each include an Entity selector — use it to control which records your team sees.

View selectedWhat it shows
Parent / client nameRecords assigned directly to the parent.
All entities (e.g., all offices, locations, branches)Parent plus child entity records.
One specific entityRecords assigned directly to that entity. The Entity column shows which entity each row belongs to.
creating & assigning entities
  • Client admins create child entities — offices, locations, branches, or teams — directly in alphaScreen.
  • CSV import creates multiple child entities and their direct member assignments at once, using the provided template.
  • Required columns: Name, Location type, Location user name, Location user email, Manager/Member designation.
  • Imported members aren’t emailed automatically. Temporary credentials, if generated, appear only in the import results — download and store them securely right away.
  • Existing direct assignments are skipped on re-import, not duplicated.
archiving entities
  • Archive a child entity once it’s no longer active.
  • Archiving hides it from active selectors and lists.
  • Historical roles, candidates, members, reports, billing, and agreements are kept — archiving does not delete them.
  • Archived an entity by mistake? Contact Support to restore it.
members caveat

Members filtering shows direct assignments for the selected entity only. Inherited or effective access is not the same as a direct assignment.
